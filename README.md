# Robert Barrett's portfolio

A lightweight, dependency-free portfolio SPA designed for GitHub Pages.

## Local preview

Serve the folder with any static file server and open `http://127.0.0.1:5173`.

## Personalize the site

- Update the copy and project cards in `index.html`.
- Update profile and contact links in `portfolio.config.js`.
- Replace the empty PostHog project token in `portfolio.config.js` when analytics is ready.

PostHog is disabled on localhost by default, uses deliberate custom events instead of autocapture, and starts with session recording disabled.
